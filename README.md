# Windows Mobile Instrumentality Project

为 Windows Mobile / Windows CE 平台开发的软件

Software developed for Windows Mobile / Windows CE platform

1. [Localsend](https://github.com/lyk82468246/localsend-winforms)
    使用 .net/winforms 重写的 Loacalsend，目前已经支持非加密收发和加密下单向接收，加密下发送正在开发中
2. [QRCode](https://github.com/lyk82468246/qrcode-cf35)
    二维码扫描和生成
3. [rime-wm6](https://github.com/lyk82468246/rime-wm6)
    尝试移植 Rime 到 WM6 上，还有很长的路要走
4. [Positron](https://github.com/lyk82468246/Positron)
    现代互联网基础设施大集合与现代浏览器，目标是 Electron 类似物
5. [ME3630-S3C6410-WM6](https://github.com/lyk82468246/ME3630-S3C6410-WM6)
    尝试给 WM6 设备接入 LTE 网络
